## Прийняті зміни поведінки

- Ввід для анімації: 2–200 скінченних чисел, кома/пробіл, з від’ємними та дробовими. Counting sort використовує частоти впорядкованих унікальних значень, тому підтримує дроби й широкий діапазон без величезного буфера; для рядків/матриць показує помилку.
- Крок: обмін для bubble/selection/shell/quick/heap, злиття для merge, запис для counting; таблиця й анімація використовують той самий код. Час вимірюється без фактичного очікування кадрів.
- Генерація імен/міст використовує локальні словники замість зовнішнього API; збережено типи результатів варіантів. Обмеження розмірів захищають інтерфейс від зависання.
- Відносна Vite base та basename від URL модуля зберігають маршрути під /asd й дозволяють інші каталоги. Для прямого відкриття вкладеного маршруту сервер має повертати index.html.
